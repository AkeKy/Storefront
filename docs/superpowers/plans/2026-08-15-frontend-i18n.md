# Frontend i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an English-default, persisted English/Thai interface to the Gadget Arena storefront without changing catalog, cart, checkout, or backend contracts.

**Architecture:** A small client-side i18n feature owns the current locale, browser persistence, typed UI messages, and presentation helpers for category, stock, and badge labels. The root layout supplies it above the existing theme and cart providers. Components consume it only for customer-facing copy; `CatalogService`, product model names, cart storage, prices, routes, and order payloads stay unchanged.

**Tech Stack:** Next.js 15 App Router, React 19 context, TypeScript, Vitest, Testing Library, localStorage.

## Global Constraints

- English is the default locale; the only supported locales are `en` and `th`.
- Store an explicit customer language choice only under `gadget-arena-locale`.
- Keep the URL, category query parameters, `CatalogService` contract, product brands/models, THB prices, cart behavior, and order payload unchanged.
- Do not modify the separate `project_intern1` Go repository or add a frontend backend call.
- Preserve the global dark-default theme and its stored light preference independently from the locale.
- Translate active home, catalog, checkout, header, footer, catalog status, category, badge, and stock copy; do not reactivate legacy content components.
- Do not add URL locale prefixes, browser-language detection, currency conversion, or locale-specific SEO in this release.

---

## File Structure

- Create `src/features/i18n/messages.ts`: locale constants, English/Thai message dictionaries, and presentation maps for catalog categories, badges, and stock labels.
- Create `src/features/i18n/LanguageContext.tsx`: client context, provider, guarded locale hydration/persistence, typed `t`, and catalog-label helpers.
- Create `src/features/i18n/LanguageContext.test.tsx`: provider default, malformed storage fallback, stored Thai restore, and explicit switch coverage.
- Modify `src/app/layout.tsx`: add `LanguageProvider` above the existing providers without changing metadata or theme wiring.
- Modify active customer-facing components under `src/components/`, `src/components/catalog/`, and `src/app/`: replace hard-coded owned copy with `useLanguage`; retain canonical product strings and data contracts.
- Modify focused component tests only where accessible names or intentional visible strings change; add English-default and Thai-switch assertions.

- [ ] **Step 3: Implement typed messages and provider**

In `messages.ts`, make English the canonical key shape and require Thai to implement the same keys. Include navigation, common action, home, catalog, cart, checkout, validation, and status messages. Keep interpolation explicit, for example `catalog.productCount: '{{count}} products found'` and `cart.itemCount: '({{count}})'`.

In `LanguageContext.tsx`, initialize state to `DEFAULT_LOCALE`, restore only a valid stored locale inside `useEffect`, and persist only through `setLocale`. Use a formatter that replaces `{{name}}` tokens. Keep malformed storage and unknown translation keys safe by returning English copy. Expose category IDs (`mice`, `keyboards`, `headsets`, `monitors`) and existing badge values (`New`, `Sale`, `Limited`) through presentation maps, never by altering fixture values.

```tsx
export function LanguageProvider({ children }: { children: React.ReactNode }) {
  const [locale, setLocaleState] = useState<Locale>(DEFAULT_LOCALE);

  useEffect(() => {
    const stored = window.localStorage.getItem(LOCALE_STORAGE_KEY);
    if (stored === 'th' || stored === 'en') setLocaleState(stored);
  }, []);

  const setLocale = (nextLocale: Locale) => {
    window.localStorage.setItem(LOCALE_STORAGE_KEY, nextLocale);
    setLocaleState(nextLocale);
  };

  return <LanguageContext.Provider value={{ locale, setLocale, t, categoryLabel, stockLabel, badgeLabel }}>{children}</LanguageContext.Provider>;
}
```

- [ ] **Step 4: Add the provider to the root layout**

```tsx

  </ThemeProvider>
</LanguageProvider>
```
